# 🔔 توثيق تطبيق الباصرة (Quiz Buzzer + أوضاع لعب)

توثيق كامل: الأدوار الثلاثة، أوضاع اللعب، المعمارية، طريقة العمل، التشغيل، والنشر.

> ملف مختصر للبدء السريع في [`README.md`](./README.md).

---

## 1. نظرة عامة

تطبيق **مسابقات لحظي** للأعراس والتجمّعات. ثلاثة أدوار:

- **🙋 اللاعب** — يدخل بالكود من جواله ويلعب بكل الأوضاع.
- **🎤 المضيف** — ينشئ الغرفة، يختار وضع اللعب، يؤلّف السؤال، يبدأ الجولة ويعرض النتيجة.
- **📺 شاشة العرض** — تُعرض على التلفزيون/بروجكتر، يتابع الجمهور النتائج والمؤقّت والصدارة لحظياً.

**العدالة:** في وضع الباصرة، ترتيب الضغط يتحدد من **ساعة السيرفر** (`created_at`)، لا من سرعة نت اللاعب.

## 2. أوضاع اللعب

| الوضع | المفتاح | الفكرة | المؤقّت | الحساب |
|-------|---------|--------|:------:|--------|
| ⚡ الباصرة | `buzz` | أول من يضغط، المضيف يعطي النقطة. خيار **قفل فوري** بعد أول ضغطة. | — | يدوي (+/−) |
| 🎯 اختيار من متعدد | `mcq` | سؤال + خيارات، الكل يجاوب خلال مؤقّت. | ✅ | تلقائي: صح + **بونص سرعة** (500→1000) |
| 👨‍👩‍👧 اعرف الإجابات | `feud` | إجابات مخفية متعددة، اللاعبون يخمّنون، كل إجابة صح **تنكشف** وتعطي نقاطها. | ✅ | تلقائي: أول من يجيبها يأخذ نقاطها |
| 🔢 أقرب رقم | `closest` | سؤال رقمي، الأقرب للرقم الصحيح يكسب. | ✅ | تلقائي: 10/6/3 لأقرب ثلاثة |

> **سرّ الجولة** (الإجابة الصحيحة / قائمة Family Feud / الرقم الهدف) يحتفظ بها المضيف **محلياً** (localStorage) ولا تُكتب في قاعدة البيانات قبل الكشف — حتى لا تتسرّب للاعبين.

## 5. معمارية قاعدة البيانات

التعريف الكامل في [`schema.sql`](./schema.sql). أربعة جداول في `public`:

### `rooms`
| العمود | النوع | الوصف |
|--------|-------|-------|
| `id` | uuid (PK) | معرّف الغرفة |
| `code` | text (unique) | كود الدخول (4 حروف) |
| `mode` | text | وضع اللعب: `buzz` / `mcq` / `feud` / `closest` |
| `phase` | text | المرحلة: `lobby` / `live` / `reveal` |
| `round` | int | رقم الجولة |
| `question` | text | نص السؤال |
| `payload` | jsonb | إعدادات/نتائج الجولة (خيارات، مدة، كشف، توزيع…) |
| `round_started_at` | timestamptz | بداية مرحلة live (لمزامنة المؤقّت) |

### `players`
`id`, `room_id` (FK), `name`, `score`, `joined_at`.

### `buzzes` (وضع الباصرة)
`id`, `room_id` (FK), `round`, `player_id` (FK), `created_at` = **أساس الترتيب**.
قيد فريد `unique(room_id, round, player_id)` يمنع الضغط مرتين.

### `answers` (mcq / feud / closest)
`id`, `room_id` (FK), `round`, `player_id` (FK), `value` (الاختيار/التخمين/الرقم), `is_correct`, `points`, `created_at`.
قيد فريد `unique(room_id, round, player_id, value)` — يمنع تكرار نفس القيمة، ويسمح بتخمينات مختلفة (لـ feud).

**Realtime:** الجداول الأربعة في `publication supabase_realtime` مع `replica identity full`.

### شكل `payload` لكل وضع
```jsonc
// buzz (live):     { "lockout": true, "duration": 0 }
// mcq (live):      { "options": ["..."], "duration": 20 }
// mcq (reveal):    { ..., "correct": 1, "dist": [1,2,0] }
// feud (live):     { "duration": 60, "total": 5, "revealed": [{ "text","points","by" }] }
// closest (live):  { "duration": 30, "unit": "" }
// closest(reveal): { ..., "target": 250, "results": [{ "player_id","value","diff","points" }] }
```

## 6. كيف يشتغل (التدفّق والـ Realtime)

### دورة الجولة
1. **المضيف** يختار وضعاً ويؤلّف السؤال → يضغط "ابدأ الجولة":
   `UPDATE rooms SET mode, phase='live', round=round+1, question, payload, round_started_at=now()`.
2. **اللاعبون** يدخلون إجابتهم حسب الوضع (ضغط/اختيار/تخمين/رقم) → `INSERT` في `buzzes` أو `answers`.
3. **المؤقّت** ينتهي (أو المضيف يضغط "اعرض النتيجة") → المضيف يحسب النقاط ويكتب الكشف في `payload`:
   `UPDATE rooms SET phase='reveal', payload=...` + `UPDATE players.score`.
4. **شاشة العرض** والكل يشوفون النتيجة لحظياً + احتفال للفائز.

### الاشتراكات
- **المضيف** (`host-<id>`): `players` (الكل)، `buzzes` (INSERT)، `answers` (INSERT — يطابق Family Feud لحظياً).
- **اللاعب** (`room-<id>`): `rooms` (UPDATE → الحالة/السؤال/الكشف)، `players` (UPDATE → نقاطه)، `buzzes` (INSERT → ترتيبه).
- **العرض** (`display-<id>`): `rooms`، `players`، `buzzes`، `answers` — كلها للعرض المباشر.

> المؤقّت يُحسب عند كل العملاء من `round_started_at + payload.duration`؛ والمضيف هو من يُنهي الجولة فعلياً.

## 7. دليل الاستخدام

### المضيف
1. افتح `host.html` → "أنشئ غرفة"، وشارك الكود (وافتح شاشة العرض بزر "افتح شاشة العرض").
2. اختر وضع اللعب، املأ السؤال/الخيارات/المدة، واضغط "ابدأ الجولة".
3. تابع المباشر، ثم "اعرض النتيجة" (أو ينتهي المؤقّت تلقائياً).
4. "جولة جديدة" للسؤال التالي. لوحة النقاط فيها +/− يدوي و"تصفير".

### اللاعب
افتح `player.html` → اكتب اسمك + الكود → العب: اضغط الباصرة / اختر A-B-C-D / اكتب تخميناتك / اكتب رقمك.

### شاشة العرض
افتح `display.html` → اكتب الكود (أو افتحها من زر المضيف)، واعرضها على التلفزيون.

## 8. التشغيل محلياً

```bash
python3 -m http.server 8000
#   المضيف:  http://localhost:8000/buzzer/host.html
#   اللاعب:  http://localhost:8000/buzzer/player.html
#   العرض:   http://localhost:8000/buzzer/display.html
```

**الإعدادات** في `js/config.js` (`SUPABASE_URL` + المفتاح العام). لإعادة بناء القاعدة: شغّل [`schema.sql`](./schema.sql) في Supabase SQL Editor.
